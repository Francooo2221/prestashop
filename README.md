# Prestashop Cluster Deployment Lab

## Opis projektu
Projekt polega na wdrożeniu sklepu internetowego opartego na Prestashop 1.7.8 w środowisku konteneryzowanym przy użyciu **Docker Swarm**. Sklep działa w klastrze kontenerów, a projekt obejmuje automatyzację wdrożeń oraz testów funkcjonalnych.  

Projekt obejmuje:  
- Wdrożenie sklepu Prestashop w kontenerach przy użyciu **Docker Swarm**.  
- Skrypty inicjalizujące sklep i bazę danych **MySQL**, zapewniające pełne przygotowanie środowiska.  
- Testy automatyczne sklepu z wykorzystaniem **Selenium**, sprawdzające proces zamówienia i podstawowe funkcjonalności.  
- Wersjonowanie kodu i konfiguracji w repozytorium GitHub.

## Technologie
- Docker Swarm  
- Prestashop 1.7.8  
- MySQL  
- Selenium (automatyczne testy UI)  
- Bash / Linux  
- Ubuntu Linux  

## Zdobyte umiejętności i doświadczenie
- Tworzenie i zarządzanie środowiskiem konteneryzowanym przy użyciu Docker Swarm.  
- Automatyzacja wdrożeń aplikacji webowej w środowisku konteneryzowanym.  
- Wdrażanie sklepu Prestashop w kontenerach i konfiguracja środowiska.  
- Automatyzacja testów funkcjonalnych sklepu z użyciem Selenium.  
- Zarządzanie bazą danych MySQL i przygotowywanie skryptów inicjalizujących sklep.  
- Tworzenie i utrzymywanie Infrastructure as Code (IaC) dla aplikacji konteneryzowanej.  
- Podstawy bezpieczeństwa przy pracy z kontenerami i certyfikatami SSL.  
- Organizacja repozytorium, wersjonowanie kodu i współpraca zespołowa przy projekcie.
- Automatyzacja procesów CI/CD z GitHub Actions
